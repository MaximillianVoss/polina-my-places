# Assignment 16 — My Places

## Исходное условие

Создайте приложение, в котором можно сохранять адреса и показывать их на карте. Для хранения используйте Firebase **или** SQLite. Используйте React Native Paper в интерфейсе и React Navigation для переходов между экранами.

## Выбранное решение

В этом комплекте используется TypeScript, Expo SDK 54, SQLite на iOS/Android, React Native Paper и Native Stack из React Navigation. По кнопке SAVE адрес ищется через Photon; пользователь выбирает найденный вариант, сохраняет его и открывает карту с маркером. Для браузера предусмотрены localStorage и встроенная карта OpenStreetMap. Браузерная версия не подменяет проверку SQLite на мобильном устройстве.

Дополнения: обработка пустого ввода, недоступного сервиса, HTTP 429 и таймаута; выбор неоднозначного адреса; запрет повторного сохранения и удаление адресов.
