# Запуск из папки HW.Group-2 на Mac

Рабочая папка ученицы:

```bash
cd <папка-этого-репозитория>
```

Распакуйте отдельные архивы внутрь этой папки. В корне каждого проекта находятся `package.json` и `App.tsx`. Ожидаемые новые пути:

```text
HW.Group-2/
  build-and-run.sh
  15-shopping-list-paper/
    package.json
    App.tsx
  16-my-places/
    package.json
    App.tsx
```

Один раз разрешите запуск скрипта и запустите меню:

```bash
chmod +x build-and-run.sh
./build-and-run.sh
```

Выбирайте номер по фактическому пути в выведенном списке. Номера меню могут изменяться при добавлении проектов и не совпадают с номерами заданий 15/16. Можно выбрать обе новые папки через пробел, а затем выбрать платформу Expo.

Для продолжения №15 в исходном проекте выбирайте `[Expo] 11-shopping list SQLite/ShoppingListApp`. После замены его интерфейса название папки может остаться прежним.

На Mac для iOS выберите `ios`: нужен установленный Xcode и Simulator. Для Android нужен запущенный виртуальный телефон Android Studio. Web открывается в браузере; в №16 используется отдельный web-вариант карты и хранилища. Нативная SQLite и нативная карта проверяются на iOS/Android.

Если старый скрипт не обнаруживает новые папки, в общем комплекте есть актуальная копия `tools/build-and-run.sh`. Сначала сохраните старый скрипт под другим именем, затем перенесите актуальную копию в корень HW.Group-2.

Прямой запуск №15:

```bash
cd <папка-этого-репозитория>
npm ci
npm start
```

Прямой запуск №16:

```bash
cd <папка-этого-репозитория>
npm ci
npm start
```

`Ctrl+C` останавливает сервер. Уже распакованные проекты остаются на диске.
